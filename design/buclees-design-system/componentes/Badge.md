# Badge

Etiqueta pequeña, no interactiva, para la dificultad, el precio gratuito o el grosor de una lana.

- **Qué aporta quien lo usa:** `children` (una o dos palabras) y `tone`.
- Dificultad siempre con este código: `oliva` Principiante, `amarillo` Intermedio, `rosa` Avanzado. La palabra va siempre escrita: el color nunca es la única señal.
- `oliva` también para «Gratis». `neutral` para grosor (DK, Worsted) y categorías (Amigurumi, Mantas).

**No:** usarla como botón o filtro (para eso, `Tag`); más de tres en una tarjeta.
